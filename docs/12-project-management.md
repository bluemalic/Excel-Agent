## 3. 规格偏差的总体说明

规格书写作于实现之前（2026-10-26），实现于 2026-10-26/28 完成。以下差异**不是缺陷修复项**，
而是如实记录「计划 vs 实做」：

- 规格示例数字（§11 消融表 M0 72%/M1 81%/M2 93%）是**预估**；实测全部 100%，且 AC-7 为 0pp（见 [10 测试与评测](10-testing-eval.md)）。
- 规格 §5 的 L2「同批事实再 mem0.add」实现为确定性 L2 键 + Mem0 会话事实双轨；指代消解只依赖 L2，稳定性更好。
- 规格未提及的增量实现：流式执行与停止、会话历史回放、快照恢复、图表会话级累积、VSCode 式 UI。

## 4. 已知问题与规格偏差

| # | 问题 | 影响 | 处置建议 |
|---|---|---|---|
| 1 | AC-7 未达标（M0 100% → M2 100%，0pp） | 反思增益无法在本评测集证明 | 更弱模型或更难题目重跑；机制有效性有 r1 题重试证据 |
| 2 | AC-10 未自动化判定 | 「无编造数值」依赖人工抽查 | 增加数值溯源自动比对（回答数字 ⊆ res_id 结果） |
| 3 | `WRITE_CONFIRM_THRESHOLD`（config.py）已定义未被引用 | 二次确认阈值在调用处硬编码 50 | 统一引用常量（小改动） |
| 4 | `AgentState` 未声明 `r1_outcome/r2_outcome/failed_step` | 作为运行时临时键工作正常；类型不完整 | 补充声明或注释 |
| 5 | `python -m src.mcp_server` 不可用（缺 `__main__.py`） | 文档需写 `python -m src.mcp_server.server` | 补一个 `__main__.py`（2 行） |
| 6 | MCP 会话为全局单例 `_MCP_SESSION="mcp"` | 多 MCP 客户端共享工作簿与 pending_write | 单用户本地场景可接受；多客户端需会话化 |
| 7 | Mem0 记忆条目为英文短语（输入为中文） | 展示效果欠佳 | Mem0 提取语言可配置（升级方向） |
| 8 | Mem0/qdrant 本地锁限制并发 | 应用与评测需单实例/串行 | 文档已写明；评测并发可分片+独立数据根 |
| 9 | 冷启动 29–40s | 首次体验慢 | 后台预热 / 模型常驻 |
| 10 | `.xls` 不支持合并单元格填充 | 老格式体验降级 | 转存 `.xlsx`；或 xlrd 路径补齐 |
| 11 | 评测 M2 平均耗时 20.8s 偏高 | 受单题网络波动影响（multi/m1 单题 155.5s） | 多次取均值；记录耗时分布 |
